# ¿Sí te la sabes? · VIVA Aerobus (demo web)

Demo jugable del juego de trivia del booth VIVA para conciertos y partidos en Monterrey (Estadio Borregos, Tigres y Rayados).

## Cómo jugar
Haz clic en los botones de abajo de la pantalla, o usa el teclado:

| Tecla | Qué hace |
|---|---|
| ← → | Quién contestó primero (jugador 1 / jugador 2) |
| ↑ | Sí se la sabe (+10 puntos) |
| ↓ | No se la sabe |
| Enter | Continuar: empezar, mostrar respuesta, siguiente pareja |
| M | Menú: evento, tiempo, sonido |

En el booth se juega con un control de NES/SNES por USB con los mismos botones (la cruz, A y START).

- `probar_control.html`: prueba de un control USB (conéctalo y presiona cada botón).
- Las preguntas están en `datos/preguntas.xlsx`.
